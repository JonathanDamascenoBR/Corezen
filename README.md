# 🖥️ Corezen
 
> **Projeto Principal — Curso de Programação Full Stack (Senac)**  
> 🔗 **Acesse a aplicação ao vivo:** [Corezen na Render](https://corezen.onrender.com)
 
---
 
## 📌 Sobre o Projeto
 
O **Corezen** é uma plataforma desenvolvida como o projeto integrador principal do curso no **Senac**. O objetivo da plataforma é ajudar entusiastas e usuários que desejam montar um **setup de PC completo ou escolher jogos**, reunindo comparativos de peças, especificações e indicações das melhores promoções do mercado.
 
> **Importante:** O Corezen não vende peças diretamente; atuamos como um guia de recomendação e comparador para ajudar o usuário a tomar a melhor decisão de compra.
 
Atualmente, a aplicação encontra-se na sua **primeira fase (MVP - Minimum Viable Product)**, operando no *front-end* construído com React, consumo de dados simulados via arquivos `.json` e com deploy ativo na plataforma Render.
 
---
 
## 🚀 Tecnologias Utilizadas
 
### Front-end (Fase Atual)
- **React.js**: Biblioteca principal para construção da interface baseada em componentes reutilizáveis.
- **Tailwind CSS**: Framework utilitário para estilização ágil, responsividade e padronização visual.
- **Render**: Plataforma de hospedagem utilizada para a implantação (*deploy*) da aplicação.
 
---
 
## ✨ Funcionalidades Atuais
 
- ⚙️ **Comparador de Peças**: Comparação visual de especificações de componentes de hardware (placa de vídeo, processador, memória, etc.).
- 🕹️ **Guia e Comparativo de Jogos**: Visualização de requisitos de sistema e detalhes de jogos.
- 🏷️ **Indicação de Promoções**: Exibição de ofertas e links recomendados para compra.
- 📱 **Interface 100% Responsiva**: Adaptação completa para smartphones, tablets e desktops.
- 📂 **Mock Data (.json)**: Estrutura simulada para consumo e exibição dos dados de peças e jogos.
 
---
 
## 🔮 Próximos Passos (Roadmap)
 
O projeto está em constante evolução. Das próximas etapas de desenvolvimento, destacam-se:
 
- [ ] **Back-end Integrado**: Criação de uma API RESTful dedicada para atualização dinâmica de preços, cadastro de peças e autenticação de usuários.
- [ ] **Banco de Dados**: Integração com banco de dados para substituição da camada estática `.json`.
- [ ] **Montador de Setup Interativo**: Ferramenta no site para checar compatibilidade de peças ao montar um PC.
- [ ] **Aplicativo Mobile**: Desenvolvimento de uma versão nativa/híbrida para dispositivos móveis (Android/iOS).
